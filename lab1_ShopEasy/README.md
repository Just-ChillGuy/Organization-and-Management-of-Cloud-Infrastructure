# ShopEasy — сетевая архитектура облака

Лабораторная работа 1: проектирование сетевой архитектуры облака для интернет-магазина ShopEasy. Спроектированы VPC с тремя зонами доступности, публичные, приватные и data-подсети, балансировщик нагрузки (ALB), NAT Gateway в каждой зоне, резервирование связи с датацентром (Direct Connect + VPN), Security Groups и VPC Flow Logs.


**Авторы:** Бобров Иван, Зюзин Владислав
