# Лаба 3 — Проектирование сетевой архитектуры облака (VPC, балансировщики, связность)

Сервис — интернет-магазин ShopEasy из Лабы 1. Работа выполнена как проектирование на схеме: ресурсы в реальной облачной среде не создавались.

## Описание сервиса

**Название сервиса:** ShopEasy

**Тип сервиса:** интернет-магазин (бытовая техника и электроника)

**Целевая аудитория:** частные покупатели из России

**Основные пользовательские сценарии:**

1. Просмотр каталога и карточек товаров.
2. Вход в личный кабинет.
3. Добавление в корзину и оформление заказа.

**Состав сервисов:**

| Сервис | Назначение | Особенности (что важно для проектирования) |
|---|---|---|
| Веб-фронтенд | публичная часть магазина: каталог, корзина, кабинет | HTTP/HTTPS, порт 80, пользователи со всей России, статика кэшируется (CDN) |
| API-бэкенд | бизнес-логика: товары, корзина, заказы, авторизация | REST, пути `/api/*` и `/orders/*`, порт 8080 |
| База данных (PostgreSQL) | хранение товаров, пользователей, заказов | порт 5432, не должна быть доступна из интернета |
| Служебные сервисы | обновления ОС, мониторинг, бэкапы, телеметрия | только исходящий интернет, без входящих соединений |

**Требования к отказоустойчивости:**

- работа в трёх зонах доступности (AZ);
- фронтенд и API отдаются через балансировщик;
- у всех подсетей есть выход в интернет, у приватных и data — только исходящий;
- нет Single Point of Failure.
